## 🛠️ How to Use qiaomu-home

### 📝 Writing Daily Notes

- In the **Notes** section, click the text box and start typing.
- Press **Enter** to save your note.
- Your notes are stored automatically—no need to press save.

### ✅ Managing Your To-Do List

- Click the **To-Do** tab at the top of the page.
- Type a task and press **Enter** to add it.
- Click the checkbox next to a task to mark it complete.
- Click the **X** to delete a task you no longer need.

### 🔖 Adding Common Entries (Links)

- Find the **Links** or **Shortcuts** area on the page.
- Click the **"+"** button to add a new link.
- Paste the website address and give it a name.
- The link will appear as a button—click it anytime to visit that site.

### 📖 Building Your Reading List

- In the **Reading** section, paste a link to an article you want to save for later.
- Add a short note about why you saved it (optional).
- Your reading list stays tidy and accessible whenever you're ready to dive in.

## 🧭 Troubleshooting

**Problem: The app won't open.**
- Make sure you double-clicked the downloaded file, not just looked at it.
- Try right-clicking the file and selecting **"Run as administrator."**

**Problem: I can't see my saved notes.**
- Check that you're running the app from the same location where you first opened it. If you moved the file, your data might be in the old folder.

**Problem: The page looks weird or stretched.**
- Try pressing `Ctrl + 0` (zero) to reset the zoom level in your browser.

**Problem: I want to start fresh.**
- Go to Settings → Clear All Data. This will erase everything and start qiaomu-home like new.
